# Recommendation-quality rubric

Score each generated or deterministic fixture from 0 (fail) to 2 (strong). A product-quality PASS requires no zero in a release-critical dimension and an explicit note for any dimension that is not exercised.

| Dimension | 0 — fail | 1 — acceptable | 2 — strong |
|---|---|---|---|
| Occasion/formality fit | Implausible for the stated setting | Usable but generic or slightly off | Clearly suited to the occasion and context |
| Completeness | Missing required role or duplicate piece | Complete with a weak gap | 3–6 unique pieces with upper/lower/footwear, or a justified traditional exception |
| Coherence | Conflicting colour/material/silhouette | Wearable but unremarkable | Intentional palette, texture, proportion, and footwear |
| Wardrobe integrity | Claims sample/catalogue item is owned or invents inventory | Ownership is mostly clear but ambiguous | Local ownership is authoritative; samples and missing pieces are honest |
| Weather discipline | Uses unstated weather or ignores explicit weather | Weather affects one detail | Weather changes layers/materials only when explicitly supplied |
| Replacement fidelity | Changes unrelated roles or loses garments | Correct role with minor drift | Replaces only the selected role and preserves all other pieces |
| Explanation quality | Contradictory, long, or empty | One useful reason | Concise summary plus no more than three specific reasons |

Use deterministic unit/mock tests for the default cycle. The optional live evaluator is paid-provider work and remains out of scope unless the user explicitly approves it.
